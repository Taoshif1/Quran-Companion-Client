# Third-Party Notices

## Tanzil Project Quran Text

Quran Companion includes the Tanzil Project Uthmani Quran Text, version 1.1, obtained from [https://tanzil.net/download/](https://tanzil.net/download/). The Quran text must remain verbatim and Tanzil Project must be identified and linked so users and developers can track updates.

The Arabic corpus bundled with this client is deterministically generated from the unchanged canonical XML held by the server repository. Its recorded SHA-256 protects this project copy from accidental modification; the checksum is not an independent religious-authenticity proof.

Tanzil’s Uthmani text is intended to represent the Medina Mushaf. Quran Companion is not endorsed by the King Fahd Complex.

## QuranEnc translations of meaning

Selected Bengali translations of meaning, when available, come from [QuranEnc.com](https://quranenc.com/). Translation text and footnotes remain unmodified and are cached with their exact resource key and version. Quran Companion does not silently substitute translation resources or versions.
